# Omnidesk AI Analytics

Дашборд для анализа чатов, клиентов и менеджеров через AI.

## Быстрый старт

### 1. Установите Node.js
Скачайте с https://nodejs.org (версия 16+)

### 2. Запустите сервер
```bash
node server.js
```

### 3. Откройте браузер
```
http://localhost:3000
```

### 4. Настройте в интерфейсе

В разделе **Настройка**:

**Omnidesk:**
- Поддомен: `yourcompany.omnidesk.ru`
- Email: email вашего аккаунта
- API-ключ: Omnidesk → Настройки → API

**AI (OpenRouter):**
- Ключ: https://openrouter.ai/keys (бесплатный tier есть)
- Модель: `anthropic/claude-sonnet-4` (или любая другая)

## Что умеет дашборд

| Функция | Источник данных |
|---------|----------------|
| Список обращений с фильтрами | `GET /cases.json` |
| Переписка в каждом чате | `GET /cases/{id}/messages.json` |
| Рейтинг менеджеров с реальными KPI | `GET /stats_leaderboard.json` |
| Время первого ответа, SLA, оценки | Leaderboard API |
| AI-анализ каждого чата | OpenRouter → Claude |
| Кэш анализа (не тратит токены повторно) | localStorage |
| Инсайты по всем чатам | OpenRouter → Claude |
| Потоковая генерация отчётов | OpenRouter streaming |
| Экспорт в CSV | Браузер |

## Заметки

- Все ключи хранятся только в `localStorage` вашего браузера
- AI-анализ каждого чата кэшируется — повторный клик не тратит токены
- Кнопка «Обновить» в панели чата — принудительно пересчитывает анализ
- Leaderboard API Omnidesk кэшируется на их стороне (30 дней — кэш 1 день)
- Без AI-ключа дашборд работает в демо-режиме
