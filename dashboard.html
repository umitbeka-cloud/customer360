Omnidesk API
Откройте Omnidesk → Настройки → API. Скопируйте ключ и укажите ваш поддомен. Данные загружаются напрямую из вашего аккаунта.
При 429 ошибке запросы автоматически повторяются с экспоненциальной задержкой. Загрузка идёт по 100 обращений с адаптивной паузой (~3–4 req/sec). Для первой полной выгрузки используйте «Полная выгрузка», затем сохраните JSON. При следующих запусках используйте «Только новые» — загружает только обращения новее самого свежего в архиве.
AI (OpenRouter)
Используется OpenRouter — универсальный шлюз к любым AI-моделям (Claude, GPT, Gemini и др.). Получить ключ: openrouter.ai/keys
PostgreSQL — История тарифов
Подключение к БД для отображения истории подписок в профиле компании. Перед первым запуском выполните: npm install pg
PostgreSQL — TrustMe (NPS / CSAT)
Отдельное подключение к базе trustme для данных NPS и CSAT. Таблицы: contract.nps, contract.csat. Может быть тот же сервер, но другая база данных.
Как это работает
1
Подключите Omnidesk
Укажите поддомен, email and API-ключ выше. Данные чатов загружаются напрямую из вашего аккаунта Omnidesk через REST API.
2
Добавьте ключ OpenRouter
Получите API-ключ на openrouter.ai/keys. Ключ хранится только в вашем браузере — localStorage.
3
Нажмите «Обновить»
Дашборд загружает чаты, связывает сотрудников с их компаниями через API и отправляет историю в Claude для выявления сквозных болей компании.
Данные и экспорт
Сохраняйте архив локально чтобы не грузить заново при каждом запуске. Users.json нужен для отображения имён клиентов в чатах — выгрузите один раз и загрузите обратно.
